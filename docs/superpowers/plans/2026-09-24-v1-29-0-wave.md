# Conventions v1.29.0 wave — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every member of `REPOSITORIES.md` on conventions v1.29.0, and every member that carries `.claude/agents/translator.md` carrying the README's new translator adapter beside a new `editor.md` and `backreader.md`.

**Architecture:** One pull request per member, titled "Conventions v1.29.0", on branch `conventions-v1-29-0` in a worktree `../<repo>-conventions-v1-29-0`, opened by one script in the family's re-sync order and merged one at a time on the owner's word. The adapters are copied from the README recipe of the v1.29.0 tag, so what a member carries is byte for byte what the recipe says.

**Tech Stack:** POSIX sh, git, `gh`, each member's own suite.

**Spec:** `docs/superpowers/specs/2026-09-24-german-pipeline-design.md`, section 6 step 1 and section 4's adapters.

## Global Constraints

- Order, from `REPOSITORIES.md`: design; robertblust.github.io, guestgraph.github.io, companygraph.github.io; robertblust/mental-model, companygraph/mental-model, meta-model; service-conventions; engine; connector-apaleo; mcp-server, chat-server, mcp-blust-ch, mcp-companygraph-io; obsidian-plugin; field-notes; guestgraph/.github, companygraph/.github.
- Each member moves three things: the tag in `conventions.json`, the vendored folder and block through `sh conventions/conventions-sync sync`, and the `uses: robertblust/conventions/.github/workflows/check.yml@<tag>` line, found by anchoring on `conventions/.github/workflows/check.yml@` and never on `check.yml@` alone, which also hits `instance-check.yml@`.
- The adapters change only where `.claude/agents/translator.md` exists. As of this plan all fourteen such copies are byte-identical to the v1.28.0 recipe; a member whose copy differs is left alone and reported, not overwritten.
- `export PATH=/opt/homebrew/bin:$PATH`. Remotes over ssh push through `git -c credential.helper= -c credential.helper='!gh auth git-credential' push https://github.com/<owner>/<repo>.git <branch>`.
- A zsh loop variable is never named `path`.
- A member's suite is run where it reads the changed files; the pull request says which ran. Merging mcp-blust-ch and mcp-companygraph-io runs their deploys and needs the owner's word for each.
- Merge with single `gh pr merge <n> --repo <r> --merge` calls; a BEHIND branch takes `gh pr update-branch` and a fresh check first. Never chain a branch delete to a merge.

## Review Focus

- A member whose `translator.md` was edited by hand must not be overwritten. The script compares the file to the old recipe first.
- A member two releases behind (the two `.github` repositories were on v1.27.0) must still land on v1.29.0 with one sync.
- The sites' and design's branches go BEHIND within the day when anything else merges there; merge them first or expect the refusal.

- [ ] **Step 1: Write the wave script**

`~/.cache/wave-v1-29-0/wave.sh`:

```sh
#!/bin/sh
# Opens "Conventions v1.29.0" in one member: worktree, pin, sync, workflow line, adapters, checks, pull request.
set -eu
repo=$1                                   # e.g. robertblust/design
dir=$HOME/git/$repo
name=$(basename "$repo")
wt=$(dirname "$dir")/$name-conventions-v1-29-0
W=$HOME/.cache/wave-v1-29-0
cd "$dir" && git fetch -q origin && git checkout -q main && git pull -q --ff-only
git worktree add -q -b conventions-v1-29-0 "$wt" origin/main
cd "$wt"
sed -i '' 's/"tag": *"v1\.[0-9]*\.[0-9]*"/"tag": "v1.29.0"/' conventions.json
sh conventions/conventions-sync sync > /dev/null
for f in .github/workflows/*.yml; do
  sed -i '' 's|\(robertblust/conventions/\.github/workflows/check\.yml@\)v1\.[0-9]*\.[0-9]*|\1v1.29.0|' "$f"
done
note=""
if [ -f .claude/agents/translator.md ]; then
  if cmp -s .claude/agents/translator.md "$W/old-translator.md"; then
    cp "$W/translator.md" "$W/editor.md" "$W/backreader.md" .claude/agents/
    note=" The translator adapter is the recipe's new one, and the editor and back-reader adapters join it."
  else
    note=" Its translator adapter differs from the old recipe and was left as it is."
    echo "  ! $repo: translator.md differs from the old recipe, left alone"
  fi
fi
sh conventions/conventions-sync check
sh conventions/conventions-check
sh conventions/conventions-format
grep -q 'conventions/\.github/workflows/check\.yml@v1\.29\.0' .github/workflows/*.yml
git add -A
git commit -q -F - <<EOF
Conventions v1.29.0

v1.29.0 is the German pipeline: an editor and a back-reader beside the translator, GERMAN.md, fourteen glossary rows and a translator that works a page and writes no back-translation.$note

Verified: conventions-sync check, conventions-check and conventions-format pass.

Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>
EOF
git -c credential.helper= -c credential.helper='!gh auth git-credential' push -q "https://github.com/$repo.git" conventions-v1-29-0
gh pr create --repo "$repo" --base main --head conventions-v1-29-0 --title "Conventions v1.29.0" --body "Takes robertblust/conventions v1.29.0, the German pipeline.$note

Verified: conventions-sync check, conventions-check and conventions-format pass.

🤖 Generated with [Claude Code](https://claude.com/claude-code)"
```
